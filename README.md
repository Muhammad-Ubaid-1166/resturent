# 🍽️ Restaurant Demo Project — Python OOP Practice

This is a beginner-friendly Python project where I built a **restaurant system demo** using `class` and `@dataclass`.  
It demonstrates how Object-Oriented Programming (OOP) concepts work in real scenarios — like managing menu items, customers, and orders.

---

## 🧠 Project Purpose

✅ This project helped me practice:
- Python **classes and objects**
- Using `@dataclass` for clean data structure
- Building real-world logic (like placing orders, tracking bills)
- Improving code readability and organization

---

## 📁 File Overview

| File           | Description                                 |
|----------------|---------------------------------------------|
| `resturent.py` | Main Python script containing class logic for a basic restaurant simulation |

---

## 💻 Features

- 🍔 Define restaurant items using `@dataclass`
- 🧾 Create customer orders
- 💰 Calculate total bill
- 🔁 Loop to simulate multiple orders
- 🧼 Beginner-level code — easy to read and extend
